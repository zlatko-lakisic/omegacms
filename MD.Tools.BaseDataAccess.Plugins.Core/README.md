# MD.Tools.BaseDataAccess.Plugins.Core

Plugin model for **database and file** providers.


Project **Product** (from the .csproj file): OmegaCMS


## Build

From the repository root, run:

    dotnet build .\MD.Tools.BaseDataAccess.Plugins.Core\MD.Tools.BaseDataAccess.Plugins.Core.csproj -c Debug

**Target framework:** net10.0
