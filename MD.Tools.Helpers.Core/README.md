# MD.Tools.Helpers.Core

Shared helper libraries (e.g. e-mail, utilities) referenced across the solution.


Project **Product** (from the .csproj file): OmegaCMS Helpers
This project may produce a **NuGet** package when packed (see the .csproj).

## Build

From the repository root, run:

    dotnet build .\MD.Tools.Helpers.Core\MD.Tools.Helpers.Core.csproj -c Debug

**Target framework:** net10.0
