# MD.CMS.Administration.Core

Core **admin** host and bootstrapping for the static administration app. The client app, **Yarn**, and **Gulp** live under the parent `MD.CMS.Administration` folder.


Project **Product** (from the .csproj file): OmegaCMS
This project may produce a **NuGet** package when packed (see the .csproj).

## Build

From the repository root, run:

    dotnet build .\MD.CMS.Administration\MD.CMS.Administration.Core\MD.CMS.Administration.Core.csproj -c Debug

**Target framework:** net10.0
