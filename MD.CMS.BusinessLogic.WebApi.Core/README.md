# MD.CMS.BusinessLogic.WebApi.Core

Bridges the core business layer to the REST/Web API (controllers and integration points).


Project **Product** (from the .csproj file): OmegaCMS
This project may produce a **NuGet** package when packed (see the .csproj).

## Build

From the repository root, run:

    dotnet build .\MD.CMS.BusinessLogic.WebApi.Core\MD.CMS.BusinessLogic.WebApi.Core.csproj -c Debug

**Target framework:** net10.0
