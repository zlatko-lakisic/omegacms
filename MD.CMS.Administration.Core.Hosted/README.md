# MD.CMS.Administration.Core.Hosted

**Hosted** ASP.NET Core site for the operator administration experience (IIS / Kestrel).


Project **Product** (from the .csproj file): OmegaCMS Hosted Administration


## Build

From the repository root, run:

    dotnet build .\MD.CMS.Administration.Core.Hosted\MD.CMS.Administration.Core.Hosted.csproj -c Debug

**Target framework:** net10.0
